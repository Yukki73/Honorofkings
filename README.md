# 👋 欢迎来到我的 《王者荣耀》/ Honor of Kings 知识分享库！

欢迎大家来到这个关于 **《王者荣耀》（Honor of Kings / HoK）** 的知识分享空间！

随着这款在中国大陆极具人气的 MOBA 手游推向全球（Global 版），我创建了这个仓库，旨在与广大玩家交流与分享关于 **装备（Item）** 和 **铭文（Arcana）** 的深度解析与实践心得。

---

## 📌 本仓库包含哪些内容？

本仓库专注于剖析《王者荣耀》中的装备与铭文机制，帮助大家更好地理解不同英雄的属性上限与出装策略：

- 🛡️ **装备深度解析**：拆解各类装备（物理、法术、防御、移动、游走、打野）的属性、被动效果及最佳出装时机。
- 🔮 **铭文搭配指南**：针对不同职业（坦克、战士、刺客、法师、射手、辅助）的铭文搭配方案与收益分析。
- ⚔️ **针对性出装（Counter Item）**：针对敌方特定英雄或阵容的局中改出装（克制出装）技巧。
- 💡 **版本热门 Build**：结合最新版本/Meta，推荐高效的“装备 + 铭文”组合方案。

---

## 🗺️ 目录结构

- `/items/` — 按分类整理的装备详细说明与实战分析。
- `/arcana/` — 铭文系统详解及各类英雄通用/专用铭文页推荐。
- `/builds/` — 具体英雄的完整出装与铭文图文方案。

## 🚀 为什么理解“装备”与“铭文”如此 vital？

在《王者荣耀》的对局中，前期细微的铭文属性差异以及中后期灵活的对位出装，往往是决定对线优势与团战胜负的关键。深入理解每一件装备与铭文的效能，能显著提升游戏理解（Game Sense）与胜率！
